# IMDb Top 1000 Movies Research

An exploratory data analysis (EDA) project analyzing factors such as ratings, box office performance, and directors using the IMDb Top 1000 movies dataset.

## Repository Structure
├── main.ipynb          # Main Jupyter Notebook containing analysis & visualizations
├── imdb_top_1000.csv   # Dataset used for research
└── README.md           # Project documentation

---

##  Environment & Prerequisites

To run this project, make sure you have the following installed:

- **Python 3.x**
- **Jupyter Notebook** or **JupyterLab**
- Required Python Libraries:
  - `pandas`
  - `numpy`
  - `matplotlib`
  - `scikit-learn`
  - `scipy`
